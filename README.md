# STL8 CBM Crew Dashboard

Ready-to-upload React/Vite dashboard for the STL8 Condition Based Monitoring Program.

## Demo Login
- Admin User PIN: `1111`
- Editor User PIN: `2222`
- Viewer User PIN: `3333`

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Upload this project to GitHub.
2. Go to Vercel.
3. Import the GitHub repository.
4. Click Deploy.
